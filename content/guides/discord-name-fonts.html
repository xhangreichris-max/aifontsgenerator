Quick answer: fancy fonts work in your Discord display name and in server nicknames, but not in your username. Discord limits usernames to plain lowercase letters, numbers, underscores and periods. To make a chat message bold, italic or underlined, use Discord's built-in Markdown, like **bold**, instead of pasted Unicode letters.

Below you'll find what each name field accepts, which styled alphabets are least likely to turn into boxes, and how to keep your name easy for friends to find.

Which Fancy Styles Are Safest for a Display Name

A styled name only works if the reader's device has a font that can draw those characters. When it doesn't, they see empty boxes, and our guide to the boxes problem covers why that happens.

To compare styles, we ran the word Shadow through eight styles from this site and did a glyph coverage check of nine free fonts: Noto Sans, Noto Serif, Noto Sans Mono, Noto Sans Math, Noto Sans Symbols, Noto Sans Symbols 2, DejaVu Sans, DejaVu Serif and DejaVu Sans Mono. For every character, we looked for a matching glyph in each font file. This doesn't tell you which fonts Discord uses, and it covers free font files only, not the system fonts your phone or computer actually ships with. It shows how widely each set of characters is covered in those files.

The coverage column means this. Wide: every character is in at least one everyday text font from that list (the three Noto Sans, Serif and Mono fonts and the three DejaVu fonts). Needs a math font: only Noto Sans Math had every character.

How to Change Your Display Name and Server Nickname

These steps come from Discord's help center. Menu names may change as the app updates.

Display name, on desktop or in a browser:

  1. Open User Settings.
  2. Go to My Account, then Profiles.
  3. Type your new display name and save.

Server nickname:

  1. In the server, right-click your own name in the member list, or on one of your recent messages.
  2. Choose Edit per-server profile.
  3. Type the nickname and press Save.

You can also type /nick followed by the new name in a text channel, or set it under User Settings, Profiles, Per-server Profiles. In every case your role needs the Change Nickname permission. If the server has turned that off for your role, ask a moderator to change it.

Your username is changed separately, with the Edit button next to Username on the My Account page. It will only accept the plain characters from the table above.

How to Bold, Italic and Underline Text on Discord

For messages, you don't need a font generator at all. Discord uses Markdown: you type a few symbols around your words, and the app formats them. These come from Discord's Markdown Text 101 article:

  • Bold: **text**
  • Italic: *text* or _text_
  • Bold italic: ***text***
  • Underline: __text__
  • Strikethrough: ~~text~~
  • Spoiler: ||text||
  • Headers: #, ## or ### and a space at the start of a line
  • Subtext: -# and a space at the start of a line
  • Code: one backtick on each side for inline code, three for a code block
  • Block quote: > and a space at the start of a line

You can stack some of them, such as __**underline bold**__. Discord also notes that a code block cancels spoiler formatting.

Markdown bold and pasted bold behave differently. When you send **Shadow**, the letters are still a normal S, h, a, d, o and w, and Discord only changes how they look. Pasted 𝗦𝗵𝗮𝗱𝗼𝘄 is six separate characters from the math alphabets. That matters for search, because someone typing shadow is matching plain letters. It also matters for screen readers, which may spell styled characters out one at a time or skip them. Our guide to fancy fonts and screen readers goes through what listeners actually hear.

Discord files Markdown under chat formatting, so it's meant for messages. For a bold look in a name field, people usually paste Unicode characters instead, with the trade-offs covered above.

Keep a Plain Name Findable

Discord's help center says people can find you for an @mention by typing either your display name or your username. Your username is always plain lowercase text, so that route always works. Your display name is what people see most, though, and a fully styled one is hard to type.

The easy fix is to mix styles. Keep at least one plain word in your display name, like Shadow 𝕊𝕙𝕒𝕕𝕠𝕨 or ✦ Shadow ✦, so friends can type what they see. Save heavier styling for a nickname in one server, where people already know who you are. And when you give out your name, share the username rather than the styled display name.
